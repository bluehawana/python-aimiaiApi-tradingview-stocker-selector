# 🎯 最终解决方案

## 问题总结

1. ❌ aimiai.com API - 用于 LLM，不是股票数据
2. ❌ 通达信 .cod/.mdt 文件 - 二进制格式，难以解析
3. ⚠️ akshare - 网络不稳定，经常超时

## ✅ 推荐解决方案

### 方案 1: 从通达信导出 CSV（最简单）

1. **打开通达信软件**
2. **选择股票** → 右键 → **数据导出** → **CSV 格式**
3. **导出字段**: 日期、开盘、最高、最低、收盘、成交量
4. **保存到**: `D:\projects\TW\data\csv\`
5. **文件命名**: `股票代码.csv` (如 `600036.csv`)

然后运行:

```bash
python analyze_akshare_data.py --data-dir data/csv
```

---

### 方案 2: 使用你已有的数据（11 月 6-17 日）

你在 `D:\projects\TW\src\data\` 已经有 8 天的数据！

虽然是通达信格式，但我们可以：

1. **在通达信中打开这些日期的数据**
2. **批量导出为 CSV**
3. **放到 `data/csv/` 目录**

---

### 方案 3: 手动下载（最可靠）

从东方财富、同花顺等网站手动下载 CSV 数据：

1. 访问 http://quote.eastmoney.com/
2. 搜索股票代码
3. 下载历史数据（CSV 格式）
4. 保存到 `data/csv/`

---

## 📊 CSV 文件格式

需要的列（中文或英文都可以）:

```csv
日期,开盘,最高,最低,收盘,成交量
2024-11-06,45.20,45.80,45.10,45.50,125000000
2024-11-07,45.60,46.20,45.40,46.00,135000000
```

或:

```csv
date,open,high,low,close,volume
2024-11-06,45.20,45.80,45.10,45.50,125000000
2024-11-07,45.60,46.20,45.40,46.00,135000000
```

## 🚀 使用 CSV 数据分析

一旦有了 CSV 文件:

```bash
# 分析 CSV 数据
python analyze_akshare_data.py --data-dir data/csv
```

系统会自动:

1. ✅ 读取所有 CSV 文件
2. ✅ 计算 MCDX 指标
3. ✅ 分析成交量
4. ✅ 找出符合 4 大标准的突破日
5. ✅ 导出结果到 CSV
