# 如何导出通达信数据为 CSV 格式

## 问题

当前数据是通达信 `.cod` 和 `.mdt` 二进制文件，无法直接读取。

## 解决方案

### 方法 1: 从通达信软件导出（推荐）

1. **打开通达信软件**

2. **选择股票** → 右键 → **数据导出**

3. **选择导出格式**: CSV 或 Excel

4. **选择导出字段**:

   - 日期
   - 开盘价
   - 最高价
   - 最低价
   - 收盘价
   - 成交量

5. **导出到文件夹**:

   ```
   D:\projects\TW\data\csv\
   ```

6. **按日期组织**:
   ```
   D:\projects\TW\data\csv\
       ├── 20251106.csv
       ├── 20251107.csv
       ├── ...
       └── 20251117.csv
   ```

---

### 方法 2: 使用通达信批量导出工具

1. 打开通达信
2. 工具 → 数据导出 → 批量导出
3. 选择日期范围: 2024-11-06 到 2024-11-17
4. 选择导出格式: CSV
5. 导出

---

### 方法 3: 提供原始 ZIP 文件

如果你有原始的 ZIP 文件（包含 CSV/Excel），请：

1. 将 ZIP 文件放到桌面
2. 运行 `1_IMPORT_DATA.bat`
3. 系统会自动读取

---

## CSV 文件格式要求

导出的 CSV 文件应包含以下列：

```csv
代码,日期,开盘,最高,最低,收盘,成交量
600036,20241106,45.20,45.80,45.10,45.50,125000000
600036,20241107,45.60,46.20,45.40,46.00,135000000
...
```

或英文列名：

```csv
code,date,open,high,low,close,volume
600036,20241106,45.20,45.80,45.10,45.50,125000000
...
```

---

## 导出后的使用

导出为 CSV 后：

1. 将 CSV 文件放到 `data/csv/` 目录

2. 运行分析：

   ```bash
   python analyze_csv_data.py
   ```

3. 或者将 CSV 打包成 ZIP：

   ```bash
   # 将所有 CSV 文件压缩
   # 文件名: 20251106.zip, 20251107.zip, ...
   ```

4. 然后使用现有的分析工具
