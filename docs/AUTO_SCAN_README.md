# 🚀 全自动 Shannon 扫描 - 使用指南

## 快速开始

### 一键运行 (推荐)

```bash
RUN_AUTO_SCAN.bat
```

或者

```bash
AUTO_SCAN_ALL.bat
```

**就这么简单！** 系统会自动：

1. 下载全市场数据 (180 天, 5000+ 只股票)
2. 扫描 Shannon 候选
3. 打开结果文件夹

## 📁 输出文件

运行后会在 `results/` 文件夹生成：

- `all_shannon_*.csv` - 全部候选
- `super_shannon_*.csv` - 超级信号 (>=80 分)
- `tech_shannon_*.csv` - 科技股候选
