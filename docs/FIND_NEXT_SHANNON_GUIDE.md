## 🔍 我们的筛选标准

### 标准 1: 金叉 (Golden Cross)

- **定义**: SMA Profit Chips 上穿 SMA Locked Chips
- **要求**:
  - 已金叉: SMA PC > SMA LC
  - 接近金叉: 差距 < 10%
- **时间范围**: 近 2-3 个月

### 标准 2: 成交量暴增

- **计算**: 当天成交量 / 30 日平均成交量
- **要求**: >= 3.0x (300%)
- **示例**: 正常 30M → 突破日 90M+

### 标准 3: MCDX 指标

- **Profit Chips (PC)**: >= 95% (接近 100)
- **SMA Profit Chips**: >= 80% (深红色线)
- **含义**: 筹码高度集中，获利盘充足

### 标准 4: 价格涨幅

- **要求**: 当天涨幅 >= 5%
- **上限**: < 20% (过滤异常)
- **含义**: 有明显的突破动作

## 📁 输出文件

### CSV 导出

`results/akshare_breakout_YYYYMMDD_HHMMSS.csv`

包含字段:

- symbol: 股票代码
- breakout_date: 突破日期
- close: 收盘价
- price_gain: 涨幅%
- volume: 成交量
- volume_ratio: 成交量比率
- profit_chips: PC
- sma_profit_chips: SMA PC
- locked_chips: LC
- golden_cross_status: 金叉状态
- behavior: 行为模式
- latest_date: 最新日期
- latest_close: 最新价格

### 调整筛选标准

```bash

python analyze_akshare_data.py --data-dir data/tushare \
  --min-pc 90 \
  --min-sma-pc 75 \
  --min-gain 3 \
  --min-volume 2.5

# 提高标准，只要最强的
python analyze_akshare_data.py --data-dir data/tushare \
  --min-pc 98 \
  --min-sma-pc 85 \
  --min-gain 7 \
  --min-volume 3.5
```

### 参数说明

| 参数         | 默认值 | 说明                  |
| ------------ | ------ | --------------------- |
| --min-pc     | 95.0   | 最小 Profit Chips     |
| --min-sma-pc | 80.0   | 最小 SMA Profit Chips |
| --min-gain   | 5.0    | 最小涨幅%             |
| --min-volume | 3.0    | 最小成交量比率        |
